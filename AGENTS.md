# CourtSense development

Canonical user repository: Rando2020/volleyballA.

Keep all analysis claims honest: this version uses manual tags and screen-space trajectory annotations. Do not imply automated inference, calibrated dimensions, complete-match coverage, or causal coaching conclusions.

Keep real footage and player records out of git. Sample data must be labeled and isolated. Preserve private access for the hosted preview.

Run `node --check dist/app.js` and `node test.mjs`. Browser QA must separately verify import, trim preview, editing, persistence after reload, supported-browser clip export and a narrow viewport. Passing logic tests alone is not visual or media approval.

Preserve unknown states and metric denominators. Set quality and attack outcome are separate. Mishit is a separate tag.

Follow the design principles in README.md. Keep controls accessible, position-specific and responsive.
